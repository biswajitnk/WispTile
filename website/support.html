Documentation & Help Center

Everything you need to know about setting up, tiling, and restoring projects with WispTile.

1. First Run & Accessibility Permissions

macOS protects window management behind Accessibility permissions. WispTile requires this permission strictly to read window coordinates and move windows to their designated zones. WispTile never reads your screen pixels or document text.

  1. Open System Settings on your Mac.
  2. Navigate to Privacy & Security → Accessibility.
  3. Toggle on WispTile.
  4. If WispTile does not appear, click the + button and select WispTile from your Applications folder.

2. Default Keyboard Shortcuts

Action Default Shortcut Description
Quick Switcher ⌥Space Open floating project switcher palette
Restore Project 1..9 ⌥1 .. ⌥9 Directly restore assigned project workspace
Tile Left Half ⌥⌘← Tile active window to the left 50% zone
Tile Right Half ⌥⌘→ Tile active window to the right 50% zone
Capture Current Desktop ⌥⇧C Save open windows into a new project

3. Multi-Monitor & Notch Adaptation

When you unplug your external monitor at the end of the day, WispTile automatically redistributes your open windows to your built-in MacBook screen without piling them on top of each other.

On 14-inch and 16-inch MacBooks with a notch, WispTile reads macOS safeAreaInsets so windows will never intrude behind the physical camera cutout or menu bar.

4. In-App Diagnostics & Privacy

Need to report an issue? Open WispTile Settings → Privacy and Data → Send diagnostics to support.

WispTile generates a 100% sanitized diagnostic bundle showing display topology, compatibility, and error codes. Personal usernames, emails, window contents, and keys are automatically redacted.
